# DeepSeek
好的，下面是一份**可直接上手的 MVP 执行路线图**。我把整个工程拆成了 **7 个阶段，约 20 个里程碑，每个里程碑都对应着具体的技能卡片和验证标准**。你只需要按顺序把技能卡片交给 Claude Code，它就能逐块实现，你负责验收。

---

## 🧱 项目总览

**目标**：一台电脑上运行两个进程（UE 和 BS），通过仿真信道（UDP 打洞或共享内存）完成一次 **“开机 → 小区搜索 → 随机接入 → RRC 连接 → NAS 附着 → 数据传输”** 的完整双向通信。

**技术栈**：
- 语言：C（协议栈主体） + Python（参考模型/测试/可视化）
- 构建：CMake + Google Test
- 信道：Python 进程模拟 AWGN/简单衰落
- 日志：统一格式，Python 脚本绘制消息序列图
- 版本控制：Git，每个技能一个分支，测试通过后合并

## 🤖 如何与 Claude Code 协作（每日工作流）

1. **你为今天要实现的里程碑编写或找到对应的技能卡片**（我已列出名称，你可以让我单独生成每一张的详细内容）。  
2. **在 Claude Code 中 `@` 引用该卡片，下达具体指令**，例如：  
   > “根据 `.skills/mac_rach_ue.md` 实现 UE 的随机接入过程，完成后编译并运行 mock 测试，直到通过。”  
3. **Claude Code 会读取卡片，写出代码，编译，运行测试。若失败会查看日志自行修改**。  
4. **你检查最终测试报告和日志 MSC 图**，确认无误后，将该里程碑标记完成，进入下一个。  
5. **每周末做一次全栈集成测试**，确保之前通过的里程碑在新环境下仍然正常。
