# M9 FEC + HARQ

## 目标
为空口引入前向纠错与混合自动重传，把"丢包即丢失"变为"可恢复"——
无线可靠性的根基。

## 组成

### FEC（`stack/phy/include/phy/fec.h`）
- 卷积码 K=7, rate 1/2, 生成多项式 133o/171o（NASA 标准），尾比特归零
- Viterbi 硬判决译码；支持逐比特擦除标记（soft==2 → 中性度量）
- CRC16-CCITT 传输块完整性；CRC 失败的块不递交上层

### HARQ（`stack/core/include/core/harq.h`）
- 停等式 4 进程轮转；传输块 = MAC PDU + CRC16 + FEC 编码
- 帧头 7 字节 `[proc|ndi][rv][len:2][info_len:2][magic=0xA9]`
  （magic 区分 HARQ 帧与传统控制帧：ACK/广播走传统路径避免递归）
- RX 软缓冲 Chase 合并：失败尝试的编码比特按位多数表决后重解码
- TX ACK 超时（80ms）兜底整帧丢失；max_retx 耗尽释放进程，
  残余丢失交由上层（M13 RLC AM）接管

## 分层语义

| 层 | 职责 | 边界 |
|----|------|------|
| FEC | 纠随机分散错误 | 突发错误超能力 → CRC 失败 |
| HARQ | 重传 + 合并，覆盖帧丢弃与残余误码 | 预算耗尽 → 应用层丢失计数 |
| RLC AM (M13) | 序号去重 + 选择性重传 | 接手 HARQ 预算耗尽的残余 |

## 关键实现事实
* **先迁态后发送**同样适用于状态无关的 HARQ：RX 的软缓冲生命周期由
  NDI 驱动（新块清旧缓冲），重传必须携带相同 NDI
* `(ns,in)` 只有唯一前驱状态可由 `hist` 记录；输入位恒为当前状态 bit K-2
* 编码比特数 `(8n+6)*2` 永非字节对齐——header 必须携带 info_len 供 RX 剥 pad
* 广播（SIB）使用专用 proc=0x7F、无反馈；ACK 控制帧走传统无封装路径

## DoD 结果 (2026-08-24)
* 单/双比特翻转全纠；BER 5% 残余 ≈0.1%（编码增益 >10×）
* HARQ 单测：30% 帧丢 + 4% 位翻转混合注入 → 全部块最终递交
* E2E：20% 丢帧信道下 101 次 burst 丢失被压缩至 ≤2 次应用层丢失
* 107/107 测试常规 + ASan 双构建全绿
