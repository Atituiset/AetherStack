# M1.4 L1 双端闭环

## 目标
UE 与 BS 通过 UDP 交换 IQ 采样，验证物理层端到端闭环。UE 发送 → 信道仿真 → BS 接收解调 → BS 回送 → UE 接收解调。

## 范围
- UDP 传输层：`UdpTransport` 封装 socket
- IQ 序列化：`iq_to_bytes` / `bytes_to_iq`
- UE 主程序：生成随机帧 → phy_tx → UDP 发送
- BS 主程序：UDP 接收 → phy_rx → 回送确认

## 接口契约

```cpp
namespace common {
class UdpTransport {
public:
    UdpTransport(const std::string& bind_ip, uint16_t bind_port);
    ~UdpTransport();
    ssize_t send_to(const std::string& dest_ip, uint16_t dest_port,
                    const std::vector<uint8_t>& data);
    ssize_t recv_from(std::vector<uint8_t>& buffer,
                      std::string& src_ip, uint16_t& src_port, int timeout_ms = 100);
};
}

namespace phy {
std::vector<uint8_t> iq_to_bytes(const std::vector<complex>& iq);
std::vector<complex> bytes_to_iq(const std::vector<uint8_t>& bytes);
}
```

## 关键参数
- UE 绑定端口 10001，BS 绑定端口 20002
- IQ 序列化格式：`[uint32_t count, float re, float im, ...]`

## 验证标准
1. UE 发送 128-bit 帧，BS 接收并解调
2. BS 回送，UE 接收并解调
3. 高 SNR 下误码率 = 0
4. 双端进程同时运行不崩溃

## 依赖
- M1.2+M1.3 OFDM 收发
- M0.2 统一日志
