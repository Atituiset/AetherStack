# 里程碑历程: M6.5 → M8

## M6.5 跨进程端到端串联 (2026-08)

位置: `docs/m6_5_plan.md`

把只在单测中存活的 MAC/RRC/NAS/RLC/PDCP 接入真实双进程，全栈贯通。

| 任务 | 成果 |
|------|------|
| T1–T5 | core 库（空口帧/定时器）、phy_io 加固、RACH MSG3 携带真实 CCCH、NAS DETACH 双端 |
| T6 | `UeNode`/`BsNode` 编排层 + 内存空口 E2E（5 用例） |
| T7 | ue/bs main 薄壳化（socket poll + tick + 命令通道） |
| T8 | sim_channel D3 端口拓扑（UL 11001→BS，DL 21002→UE） |
| T9 | `events.h` 事件目录单一事实来源；log_server 背压/`_seq`/命令转发；UE 10101 / BS 10102 命令口；心跳 |
| T10 | LMT 对齐：状态推导读事件 fields、PDU store 按 `_seq` 增量、遥测取真值 |
| T11 | `e2e_smoke.py` 跨进程冒烟 |

**过程中修复的深层缺陷**：先迁态后发送时序、TimerList 绝对时钟锚点、
`recv(timeout=0)` 阻塞语义、stdin EOF 误退出、logger 全缓冲延迟。

## M7 稳定化 (2026-08)

位置: `docs/m7_plan.md`

| 任务 | 成果 | DoD 结果 |
|------|------|---------|
| M7.1 数据回环 | UeNode 流量发生器 + 丢失扫描 + RTT 聚合 + TRAFFIC_STATS | 虚拟时钟 3000 包零丢失；直连 3 分钟 tx=1745 全达 |
| M7.2 内存审计 | `AETHER_SANITIZE=ON`（ASan+UBSan） | 93/93 零泄漏 + ASan 二进制全链路冒烟 |
| M7.3 时序稳定 | `stability_run.py` 长跑框架（RSS/停滞/崩溃守卫） | 30 分钟信道长跑 PASS：tx=17564，RSS 恒定，零崩溃零 abort |
| M7.4 异常恢复 | RACH 守卫窗自愈重试；sim_channel 黑洞/时变丢包 | 五阶段场景 PASS：50% 丢包存活→黑洞→自动续流 |

丢失率核算：ping 往返过两次信道，10% 实测 = UL 5% × DL 5% + 黑洞叠加，与理论吻合。
