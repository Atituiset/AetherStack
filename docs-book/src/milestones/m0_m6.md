# 里程碑历史 M0–M6

## M0: 项目骨架

- CMake 构建系统 (Release/Debug, Google Test)
- `logging::Logger` — JSON 格式远程日志
- `transport::UdpTransport` — POSIX UDP 封装
- Python 信道模拟器 `sim_channel.py`
- Web LMT 脚手架 (React + Vite + TypeScript)
- Git 标签: `M0`

## M1: PHY 物理层

- QPSK 调制/解调 (Gray 编码, 1/√2 归一化)
- OFDM 收发 (64-FFT, CP=16, Cooley-Tukey 原地 FFT)
- PHY I/O 序列化 (IQ↔字节, 比特↔字节)
- E2E UDP 传输: `phy_tx` → UDP → `phy_rx`
- Python 参考模型 `phy_ref.py` (NumPy)
- 15 个 PHY 测试
- Git 标签: `M1`

## M2: MAC 层

- MAC PDU 编解码 (1 字节子头 [R|F|LCID] + 变长 L)
- RACH 四步握手 FSM (UE: IDLE→WAIT_RAR→WAIT_CR→CONNECTED)
- BS RAR/CR 处理器 (RA-RNTI=0x4300|preamble, C-RNTI 递增)
- RAR 超时重试 (max_preamble_transmissions=3)
- 12 个 MAC 测试
- Git 标签: `M2`

## M3: RLC + PDCP

- RLC 透明模式 (tm_tx/tm_rx 纯透传)
- PDCP 2 字节简化头 (version + seq_num)
- 4 RLC + 5 PDCP + 4 垂直直通测试
- Git 标签: `M3`

## M4: RRC + NAS

- RRC TLV 消息 (SetupRequest/Setup/SetupComplete/Release/MIB/SIB1)
- RRC UE/BS 实体 (连接建立 FSM)
- NAS TLV 消息 (AttachRequest/Accept, IMSI ASCII, TMSI 4 字节)
- NAS UE/BS 实体 (附着 FSM, TMSI 分配)
- 10 RRC + 4 NAS + 2 完整附着测试
- Git 标签: `M4`

## M5: 可观测性 + 用户面

- AppLayer 用户面 (TX/RX 计数, PDU 跟踪日志)
- 用户面乒乓测试 (App→PDCP→RLC→MAC→PHY→AWGN→...→App)
- 4 个 user_plane + 3 个 stack 测试
- Python 分析脚本 (generate_msc, pdu_analyzer, latency_report)
- Git 标签: `M5`

## M6: Web LMT 可观测性

- App.tsx 重构: 左面板 + 右 Tab 面板
- TopologyCanvas: SVG 拓扑 (UE 圆形 + BS 矩形 + 连接动画)
- FsmViewer: 3 行 FSM (MAC/RRC/NAS) 高亮
- MscDiagram: 箭头列表式 MSC (50 条消息窗口)
- PduDetail: 十六进制详情模态框 + 层着色
- useWebSocket: 自动重连 (5 次, 指数退避)
- Git 标签: `M6`
